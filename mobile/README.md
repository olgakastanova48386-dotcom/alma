# ALMA Mobile

Первая рабочая мобильная версия ALMA для iOS и Android на Expo / React Native.

## Что уже есть

- мобильная главная в стиле ALMA;
- экран «Удиви меня» с выбором настроения;
- нижняя навигация: Главная, Удиви, Карта, Избранное, Профиль;
- заготовки экранов карты, избранного и профиля;
- конфигурация iOS и Android.

## Локальный запуск

```bash
cd mobile
npm install
npm run start
```

Для проверки типов:

```bash
npm run typecheck
```

Следующий этап: подключить авторизацию и API существующего сайта ALMA, после чего перенести реальную карту, избранное и генерацию маршрута.
